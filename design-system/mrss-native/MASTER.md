# ReMRSS 界面设计规范

## 唯一实现方案

所有设置页面、子页面和应用内弹窗统一使用 **Kotlin / Jetpack Compose / Miuix 0.9.4**。这是当前规范，覆盖早期 Java View/Canvas 玻璃风格及“仅首页试点”的迁移范围说明。

- 共享主题、卡片、设置行、开关、子页容器和弹窗位于 `MiuixComponents.kt`；首页及底部导航位于 `MiuixSettingsUi.kt`。
- 新增页面必须复用 `AppTheme`、`AppCard`、`AppRow` / `AppToggle`、`PageFrame` 和 Miuix 组件。交互控件使用 Miuix Switch、Checkbox、TextField、TextButton、WindowDialog。
- 已删除旧 GlassUi 与原生应用选择渲染器；不得恢复旧玻璃卡片、径向渐变背景或自建第二套设置组件。通用 UI 技能的输出不能替代此规范。
- Java 可以保留偏好、服务、权限、更新和生命周期控制代码；业务逻辑不应参与绘制设置界面。
- 背屏充电/通知播放及服务悬浮控制可以保留用途独立的 Android View；这不构成保留旧设置配色的理由。
- 录屏悬浮控制使用原生 WindowManager，采用与 Miuix 一致的白/深灰中性面板和按钮，颜色引用 theme_colors.xml 的共享主题令牌，录屏语义色集中在 recording_controls.xml 并随系统主题更新；录制状态使用红色圆形/停止方形，禁止恢复旧橙粉紫蓝渐变。

- 背屏通知常规模式使用全屏单层中性玻璃：仅在屏幕外缘保留轻微折射、薄高光与内侧明暗，图标、标题和正文直接排在摄像头安全区内；内容区域不得再套独立卡片、底色或阴影。Android 13+ 使用自有中性反射环境，旧系统兼容绘制；稳定后不持续刷新。主/次文字和窗口背景沿用共享主题，随系统深浅色更新；用户启用的“暗夜模式”关闭光学材质并保留纯黑背景。禁止恢复粉紫渐变、白字阴影和旧玻璃资源。
- 充电保留 `ChargingLiquidView` 的全屏绿色液体：Android 13+ 使用动态折射、波面厚度与内部光流，旧系统使用轻量兼容绘制。背景铺满可绘制区域，电量和状态文字在当前窗口排除摄像头后的安全区内居中；100% 必须填满顶部，波浪和倾斜不得露出空隙。常亮播放8秒后降低运动速度并限制到最高30fps，不可见、暂停、息屏或关闭系统动画时停止连续绘制。绿色充电、红色录制状态、琥珀色冲突警告和蓝色品牌图标属于语义色/品牌资产，可以保留。不得恢复无调用的玻璃闪电绘制分支。

## 主题与布局

- 虚拟投放期间的通知使用宿主内紧凑胶囊，位于摄像头安全区顶部；图标和两行摘要复用中性主题与通知隐私设置，按已有通知时长消失。胶囊点按后关闭，完整手势不得穿透下方App；不获取窗口焦点、不改变投放画面尺寸或背屏前台任务；投放期间充电使用同一胶囊，显示状态和电量，8秒消失或点按关闭，非投放继续使用既有全屏通知/充电动画。此场景由 `RearCastNotificationOverlay` 负责，允许独立容器，不套用全屏通知的外缘材质布局。

- 系统字体、简体/繁体中文/英文、系统字号和深色模式；不下载字体，不引入 WebView/Flutter 渲染设置页。
- 浅色页面背景 #F3F3F5、白色 Miuix 卡片；深色背景 #101013、Miuix 深色卡片。
- Compose、Activity 宿主、通知窗口和录屏浮层共用 `values/theme_colors.xml` / `values-night/theme_colors.xml`。
- 主色 #246BDF，深色强调色 #82B2FF；颜色从共享主题/语义色获取，禁止逐页另配色板。
- 卡片连续圆角 26dp、轻阴影；分组与分隔线控制密度，正文随字号自然增长。
- 页面左右边距 20dp，最大内容宽 680dp，采用 4/8dp 间距节奏；长列表使用带稳定 key 的 LazyColumn。
- 主标题 32sp、子页标题 24sp、设置名 16sp、说明 13sp；标题具备 heading 语义。
- 三个底部入口：屏幕、通知、关于。底部导航采用胶囊容器与折射选中块，支持点击、横向拖动和页面滑动联动；释放拖动后平滑停靠，系统返回遵循层级。
- 导航材质由 `NavigationControls.kt` / `BlurredNavigationFrame.kt` 统一提供：Android 13+ 使用实时背景采样、轻模糊、边缘折射、双光源高光与内阴影；旧系统使用中性实体材质，保留相同导航布局和触控反馈。玻璃底色引用共享 `theme_colors.xml`，不另设逐页配色。
- 背景采样必须排除导航自身；选中胶囊独立合成强调色页签。指示器作为覆盖层，不参与父容器测量，避免像素取整引发尺寸反馈。底栏高度随字号和标签换行增长。
- 首页先展示当前权限来源（Shizuku / Root）的授权/连接，再展示虚拟投放设置；密度兼容入口仅在虚拟投放开启时显示，物理 DPI 与方向的“背屏显示”组仅在关闭时显示。共用唤醒、遮盖、截图、充电和通知设置保留，显隐不清除任何偏好。
- 首页权限连接使用独立状态卡，提供图标、服务状态、摘要、主要操作及“权限来源”按钮；默认 Shizuku，Root 由用户主动选择和授权，不自动回退、不新增底部入口。状态变化使用礼貌播报，按钮至少48dp，宽屏适当分栏。
- 子页和应用选择器共用 `AppPageContent` / `AppPageHeader` / `AppBackButton`：左上角为玻璃圆形返回箭头，点击区域至少 48dp，保留本地化“返回”无障碍标签；不以文字按钮代替导航图标。
- 子页标题固定于顶部，列表可从其下方滚动。根据标题实测高度预留内容和焦点避让，大字号标题自然换行；应用选择器搜索、阅读位置和重建状态保持。
- 卡片内导航入口使用统一线性矢量箭头与中性材质指示，不使用文字 `›`。箭头仅作装饰，整行承接点击与无障碍；卡片内控件不得反向采样自身。

## 交互与验收

- 点击区域至少 48dp；开关整行只暴露一个 Switch 语义，装饰图标不重复朗读；状态不能只靠颜色表达。
- 数字输入保留草稿、范围校验与错误反馈；列表位置、应用选择筛选和下载会话应在重建后保持。
- 遵循系统动画缩放；支持横屏、大字号、刘海和系统栏安全区，列表底部及焦点避让浮动导航与键盘。
- 按模式显隐的设置共用 `AppSettingsReveal`：展开/淡入200ms、收起/淡出150ms，下方内容随高度平滑移动；快速切换接续当前进度，退出期间立即禁用入口，系统动画关闭时直接完成。
- 使用教程采用单列表折叠章节，默认收起、同一时间展开一章，标题直接控制正文；不另列重复目录或“返回目录”按钮。展开状态和阅读位置在重建后保留，复用共享卡片和显隐动画。
- 新页面必须与首页对照检查主题、卡片、按钮和字号，再验证功能、浅色/深色、横屏及大字号。构建和功能测试不能替代风格一致性验收。
- 保持服务/磁贴/URI 的行为和既有偏好键兼容。

## 图标

- 启动与关于页复用当前蓝色双摄/背屏图标。图形源为 `tools/generate_launcher_icons.py`。
- 系统磁贴采用单色线性矢量并交给系统着色，不保留重复密度 PNG。
- 设置页使用统一线性矢量图标；不要用表情符号替代结构图标。

# MRSS 原生设置设计

本设计根据 ui-ux-pro-max 的 Glassmorphism 查询及原生交付规则制定。首次自动设计系统给出的营销页布局不适用，未采纳。

- 实现：Java / Android View / Canvas；系统字体，不下载字体，不引入网页、Compose 或渲染引擎。
- 信息架构：屏幕、通知、关于三个底部入口；通知应用选择为子页；系统返回返回上一级。
- 材质：冷白/深蓝灰背景，柔和蓝紫色径向光晕，半透明圆角玻璃面板、细边缘高光、浅阴影。背景本身为扩散渐变，玻璃为轻量视觉模拟，不依赖小米私有材质接口。
- 浅色：主文字 #172238，次文字 #526078，蓝色 #245DE3，背景 #EEF2FA。
- 深色：主文字 #F1F5FF，次文字 #B0BCD0，蓝色 #9BBFFF，背景 #0C1322。
- 字号：标题 34sp、分组 13sp、正文 16sp、说明 13sp；随系统字号放大；正文不固定高度。
- 间距：4/8dp 节奏；手机 20dp 边距，大屏居中最大 640dp 内容宽；面板 28dp 圆角。
- 交互：原生 Switch/Button/CheckBox/EditText；至少 48dp 触控区；一致线性图标；按压涟漪，页面 180ms 淡入且遵从系统动画关闭。
- 可访问性：高对比主次文字、开关语义及标签、选中状态不只依赖颜色；系统栏/刘海/键盘安全区；深色、横屏、大字分别验证。
- 数据：旧配置原地兼容；磁贴/URI/后台服务继续使用相同键、服务与 Shizuku 逻辑。

- 横屏应用选择：屏高不足 480dp 时，左侧 240dp 可滚动筛选区，右侧列表；大字号批量按钮纵排。
- 查询边界：横屏专项查询 `orientation support` 返回了无关 Autofill，重试 `landscape` 无匹配；依据完整规则中的 orientation-support、模拟器观察和原生布局能力制定该调整，未采纳不相关搜索结果。
- 已检查文本对比度：浅色次文字/背景 5.67:1，浅色蓝色/白色 5.60:1；深色次文字/卡片 6.42:1。

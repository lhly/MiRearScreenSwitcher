# 自有通知 Mod

此独立 ZIP Mod 的设置页和背屏页都提供发布、同 ID 更新和取消按钮。背屏通知显示时，通知会覆盖背屏页；可回到主屏的 Mod 设置页继续更新或取消。导入时请单独授权 `rear.notification@1`；未授权时，宿主会拒绝请求或报告策略抑制。

界面严格区分“已进入宿主队列”和“已实际显示”。只有收到 `host.notificationResult` 的 `DISPLAYED` 事件后才显示“已实际显示”；队列接受不等于屏幕可见。宿主全局开关、勿扰、隐私和当前显示状态仍决定实际呈现。

同一 `notificationId` 的更新只覆盖这个 Mod 自己的同 ID 通知；“取消我的通知”也只能取消此 Mod 的通知。宿主在停用、卸载、撤权或 Mod 故障时清理该 Mod 的通知。

# 背屏通知单层玻璃验收

验收日期：2026-10-31。

## 最终样式

通知取消独立内容卡片及其外边距、实色背景和阴影。整块背屏共用一层中性玻璃，只有屏幕外缘的薄高光、内侧明暗和轻微折射；应用图标、名称、标题与正文作为独立前景，直接排在摄像头之外的安全区域。

Android 13+ 使用单次GPU绘制的自有反射环境；较早系统使用轻量兼容绘制。深色维持近黑灰，浅色维持中性白，不从其他应用采集画面。稳定通知不运行持续材质动画。纯黑模式完全关闭光学层，保留黑底与原有文字语义色。

当前窗口的摄像头Insets优先于缓存，窗口尚未提供信息时才使用缓存。长正文继续根据安全区实际高度截断，保留系统字号、点击跳转、通知复用、自动退出、任务恢复和充电交接。

## 真机结果

设备为2509FPN0BC，Android 17 / HyperOS OS4.0.5.0.XPBCNXM。安装正式签名的ReMRSS 3.6.0，确认 `debuggable=false`；独立验收工具使用同一正式证书签名，测试后移除，未安装调试版应用。

通过现有通知服务传入本地测试内容，检查三种主题，未发送真实消息或改变应用偏好。三次显示的窗口均为976×596，内容安全区均为 `[296,0][976,596]`，独立内容背景为空。图标、标题及两行正文均在安全区内，深色下没有内外卡片色块边界。

三种模式稳定后各采样600毫秒，对应通知窗口的FrameMetrics回调均为0，未持续重绘。该观测用于确认材质不会自发刷新，不作为长时耗电结论。测试期间临时切换的系统主题随后恢复。

# Root 权限来源

首页连接状态卡提供 Shizuku / Root 二选一，默认仍为 Shizuku。选择 Root 后点击“授权并连接”，在 KernelSU-Next 等 root 管理器中授权当前安装包。Root 模式无需 Shizuku 或 Sui。

正式版与调试版的包名不同，必须分别授权。Root 选择会保存；已成功授权的模式在应用下次启动时尝试连接。状态刷新和磁贴监听只读取状态、复用已有连接，不主动循环申请 root。授权或连接失败后由用户重试，也可以手动选择 Shizuku。

## 切换权限来源

投放、录屏或截图进行期间不能切换来源。先结束当前操作，再选择另一种权限并连接；占用检查失败或超时时会取消切换，不会自动回退到另一种权限。

Root 仅用于需要特权的背屏操作。通知使用权、通知发送、悬浮窗等 Android 权限仍需按使用功能分别授予。手机重启或临时 Root 失效后，先恢复所选权限来源，再打开 ReMRSS；授权失败时可重试或手动选择 Shizuku。

## 兼容范围

目前的实际 Root 使用结果来自 Xiaomi 17 Pro Max 和 KernelSU-Next；其他 Root 管理器、长期后台运行以及锁屏/AOD 的完整组合仍需结合设备确认。撤销授权是否立即结束已连接服务，由 Root 管理器决定。

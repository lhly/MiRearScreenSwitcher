# 带壳背屏截图

## 使用

在“背屏 → 背屏截图”开启“添加手机外壳”，可选完整机身、局部放大和黑、白、紫、绿四种配色，并可同时保存原图。默认保持原始截图。磁贴与 `mrss://screenshot` 使用同一配置与保存流程；图片保存在 `Pictures/RearDisplay`。

当前支持 Xiaomi 17 Pro / 17 Pro Max 的黑、白、紫、绿配色，自动匹配设备。首次使用联网获取，下载完成后缓存到本机，之后可离线使用。网络、模板、比例或合成失败时保存原图并明确提示，不再无条件报告截图成功。

## 使用范围

Xiaomi 17 Pro Max 已有真实设备的截图与保存结果；其他已列机型的壳图适配不代表其全部系统环境已通过真机检查。锁屏解锁交互与 Android 7 至 9 的保存兼容分支仍可能因系统不同而有差异。

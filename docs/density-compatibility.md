# 应用布局与密度兼容

打开“密度兼容”列表，为需要调整的 App 开启兼容，再设置布局 DPI。列表仅在虚拟投放开启时显示，设置从下一次投放生效。

“密度兼容”入口位于“背屏 → 投放与显示 → 密度兼容”，初始及新 App 默认关闭。开启某个 App 后，投放会保留主屏渲染 DPI，并申请让应用接受虚拟屏指定的方向、宽高比和窗口尺寸。该策略仅作用于本会话创建的可信虚拟屏，不修改全局开发者选项。系统接口缺失、调用被拒绝或功能开关未启用时，继续使用原密度兼容并提示部分适配不可用。

搜索框下方提供“全部开启”和“全部关闭”文字按钮，单击即可作用于当前查询到的全部可投放应用，不受搜索筛选影响。批量操作只更新这些应用的密度兼容开关，不修改已保存的布局 DPI；逐 App 开关仍可在批量操作后单独调整。未配置的新 App 仍默认为关闭。设置用于下一次虚拟投放，不改变当前会话。

已开启的 App 可设置 72–640 的布局 DPI。未设置数值或恢复默认时使用200，显式 URI `dpi` 参数优先，已保存的逐 App 数值保留。关闭兼容时暂不应用该 App 的布局 DPI，但保留保存值。修改用于下一次投放，当前会话保持原有方向和布局；下一次投放继续恢复该 App 已保存的旋转方向和显示范围。

数字编辑支持范围校验、草稿重建、恢复默认和键盘“完成”保存。横屏且键盘打开时收起重复说明，保留完整的数字输入区域。

摄像头避让使用系统报告的最大安全区域；全域切换和各 App 的方向、范围、DPI 选择继续保留。

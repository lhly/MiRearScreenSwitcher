# 更新镜像代理

2026-10-16完成以下本地验收，现已随[ReMRSS v3.3.3](https://github.com/lhly/MiRearScreenSwitcher/releases/tag/v3.3.3)发布；公开发布验证见[自动发版记录](github-release.md)。

## 使用方式

在“关于 → 检查更新”下方打开“镜像代理”。默认关闭，选择保存在应用设置中，切页、重启和屏幕旋转均保留。开启后，版本清单和APK下载使用第三方GH-Proxy；关闭后恢复GitHub直连。检查进行中暂时禁用开关，切换后清除上次检查结果。网页源码仓库、提交反馈和Release浏览入口沿用GitHub原地址。

代理只用于公开更新文件，无需Token，不创建VPN，也不更改系统代理。每次检查读取当前设置，每次下载固定本次路由；已有下载及其后台/旋转生命周期仍由原弹窗管理。代理不可用时显示既有失败/重试提示，可取消弹窗后关闭代理再次检查。

## 传输和校验

采用固定HTTPS前缀 `https://gh-proxy.com/`，按照[服务官方文档](https://gh-proxy.com/docs/github-accelerator)代理Raw与Release文件。它提供国内网络加速，但没有核实服务器的大陆部署位置，也不能保证所有运营商的实时可达性。使用第三方服务时会向该服务发起公开文件请求，界面说明中显示服务域名。

`version.json`格式、CI和规范APK源URL不变：清单继续要求本仓库对应版本的GitHub Release URL，不接受清单自定义代理或其他下载源。代理只添加到实际网络请求上，未将代理地址写回清单。

下载重定向只允许既有GitHub附件域，开启代理后每一跳继续经同一代理转发。拒绝HTTP、凭据、异常端口、相似域名及代理嵌套的非GitHub地址；不扩大任意域名白名单。相对跳转先在GitHub原地址上解析，再加代理前缀，避免URI规范化损坏嵌套协议。

大小上限、超时、取消/重试、SHA256、包名、升级版本及安装签名校验均保留，安装权限返回后重新校验文件。摘要和签名承担不同职责：即使代理同时修改清单与文件，APK签名仍须与已安装应用一致。

# 兼容与排障

当前 ReMRSS 宿主 App 要求 Android 16（API 36）及以上，面向 Xiaomi 17 Pro 系列及后续机型；其他机型的支持情况以实际设备验证为准。ReMRSS 根据系统报告的内置背屏和输入能力识别设备，不以分辨率相同判断所有功能兼容。当前真机使用结果主要来自 Xiaomi 17 Pro Max；其他机型、系统版本和第三方 App 的效果需结合实际环境确认。

## 无法投放或画面异常

1. 先解锁主屏，确认权限来源已运行、已授权，ReMRSS 控制服务已连接。
2. 将原背屏应用移回主屏，再重新投放。
3. 直接投放失败时，可尝试虚拟投放；虚拟方式需要 Android 13 及以上。系统无法确认背屏、触摸设备或摄像头安全区时会拒绝启动。
4. 应用缩放、固定方向或布局异常时，尝试为该 App 开启[密度兼容](density-compatibility.md)，结束当前投放后重新开始。
5. 如果应用在切屏后自行重建、退出或无法操作，分别记录直接方式与虚拟方式的表现。应用自身的登录、受保护内容、输入法和副屏限制可能影响结果。

通知、充电、截图、镜头区信息有各自的条件和兼容范围；投放可用不代表所有附加功能都可用。镜头区信息和手机壳资源范围见[镜头区域信息](camera-gap-battery.md)与[背屏截图](rear-screenshot.md)。

## 诊断信息

在“关于 → 诊断信息”或首页“连接详情”中收集，可复制 JSON 或通过系统分享面板导出文件。诊断收集在后台运行，未连接 Shizuku 时仍能导出基础信息；弹窗在 Activity 重建后保留。

报告包含应用、机型、Android/系统增量版本、Shizuku 连接和权限状态、显示候选与选中原因、cutout、输入能力、可用桌面组件、当前会话及限长的近期兼容性事件。它不读取通知内容，不导出通用 logcat，也不自动上传。分享由用户选择目标。

## 提交反馈

向 [Issues](https://github.com/lhly/ReMRSS/issues) 提供：

- 机型、系统版本和 ReMRSS 版本。
- 使用的权限来源、直接或虚拟投放方式，以及目标 App。
- 复现步骤、预期结果、实际现象；是否与锁屏、旋转、DPI、通知或充电有关。
- 失败后立即导出的诊断报告。分享前检查其中的信息，仅提交你愿意公开的内容。

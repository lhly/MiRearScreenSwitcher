# 录屏悬浮面板配色验收

2026-10-17，按用户反馈修正录屏磁贴打开后的控制台旧粉色渐变。

## 实现

- 原因：ScreenRecordService 内直接绘制橙/粉/紫/蓝四色渐变，独立于设置 UI 和原 GlassUi。
- 替换为与 Miuix 一致的浅色白底/深色深灰圆角面板，细边框和中性按钮；红色圆形表示开始录制，红色方形表示停止。
- 通过 recording_controls.xml 集中配色，在服务配置变更时原地更新主题，不重建窗口，保留按钮状态、可见性和窗口位置。
- 控件使用dp单位和48dp触控区，关闭符号改为矢量；补充按压涟漪和简繁英按钮名称/无障碍按钮语义。
- 录屏命令、Shizuku连接、视频保存和背屏持续唤醒逻辑保持原实现；停止回调的关闭控件类型泛化为View，只使用可见性接口。
- 设计规范与AGENTS已明确原生服务悬浮控件也需采用ReMRSS配色。

## 验证

- Debug、androidTest、签名Release构建通过，Lint0错误/58警告。
- API36模拟器真实WindowManager悬浮窗2项回归通过（5.935秒）：主题切换不重建窗口或重置录制UI状态/位置；实际触摸拖动后关闭并移除服务。
- 已目视复核浅色、深色和停止按钮截图，旧渐变已移除，关闭符号和红色状态清晰。
- 同样2项回归在横屏/200%字号下再次全部通过（4.834秒）；截图确认矢量图标和48dp控件不随字号溢出，窗口仍可拖动/关闭。测试后恢复字号和旋转。
- 活动录制状态通过UI状态模拟，不启动screenrecord；本轮无小米真机，不宣称实际背屏录制与文件保存复测。
- 相关证据位于`.local/diagnostics/recording-overlay-20261017/`；模拟器临时主题和悬浮权限在测试结束时恢复。

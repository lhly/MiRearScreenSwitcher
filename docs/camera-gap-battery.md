# 摄像头间电量与基础信息

虚拟投放采用“避开摄像头”范围时，可在双摄之间显示绿色玻璃竖条和居中的电量百分比。整排竖条以镜头圆心的竖直轴为中心，两侧等距竖条等长；电量从左到右点亮，上下边界随各机型的完整镜头圆弧改变，不以统一最大高度截成等高平台。百分比表示准确电量，长短不同的竖条不按面积计算电量。

## 使用

开启虚拟投放后，在“屏幕 → 镜头区域信息”中开启“摄像头间电量”。“镜头区域信息”是密度兼容下方的独立板块。此选项默认关闭，可在投放过程中即时开关。关闭虚拟投放会隐藏设置项并保留选择。

- 支持 **Xiaomi 17 Pro、17 Pro Max、18 Pro、18 Pro Max**，自动读取机型并使用各自的官方模板参数，无需手动选择。
- 17 Pro Max 已经真机目视确认；其他三款的设置说明会显示“已按本机官方模板适配，尚未真机验证”。两个开关仍默认关闭。
- 切换至“全域”时隐藏，回到“避开摄像头”后恢复。
- 该区域固定在物理镜头之间，投放 App 的旋转和 DPI 不改变其位置。
- 不增加点击或手势，也不改变投放画面大小、返回菜单和触摸坐标。
- 未适配机型、显示参数不匹配或没有独立可用间隙时不显示，投放本身继续工作。
- 原方式投放暂未接入此功能。

## 镜头区基础信息

“镜头区基础信息”可独立开启时间、日期、星期和系统天气，默认关闭，不影响电量开关。四款机型均按各自镜头圆心和半径生成圆弧：时间和日期位于右侧上下弧，星期与天气位于左侧上下弧；文字逐字沿镜头圆弧排列，并为镜头贴膜增加留边。左侧受外框圆角限制，字号放大量小于右侧；较窄机型的百分比和较长的圆弧文字会按实际可用空间缩小。17 Pro Max 用户已目视确认当前贴膜下完整可见、字号合适；其他三款以及其他贴膜厚度和开孔仍需实机确认。

- 时间遵循系统的 12/24 小时选择，显示小时和分钟；日期为月/日，星期跟随应用语言。
- 天气复用小米天气的本地缓存，显示简化天气图标与温度；摄氏度显示 `7°`，华氏度明确显示 `45°F`。没有定位请求、外部天气服务或城市数据存储。
- 天气超过六小时未更新、读不到有效数据或权限不可用时隐藏；时间和日期继续显示。天气更新依赖小米天气本身。
- 只在可见的投放会话中监听时间及天气变化。时间按分钟更新，天气恢复时读取、变化时刷新，并每十五分钟补查本地缓存；退出、全域投放或暂停时释放监听和连接。没有持续绘制动画。

天气字段和类型映射依据[小米官方主题接口](https://zhuti.designer.xiaomi.com/docs/grammar/)。系统版本可能改变读取行为；布局模板适配不代表其他三款系统天气读取已经真机验证，读取失败仍隐藏天气。

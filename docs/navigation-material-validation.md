# 导航材质验收

验收日期：2026-10-31。

## 实现范围

- 底部三个入口共用玻璃胶囊，支持点击、拖动、页面滑动联动和弹簧停靠。
- 教程、权限、背屏截图、密度兼容和应用选择器共用玻璃返回按钮及固定标题；正文、焦点根据标题实际高度避让。
- 列表导航与教程展开箭头统一使用线性矢量和中性材质指示，整行承接点击与无障碍语义。
- Android 13+ 使用实时内容采样、折射、边缘高光和内阴影；旧系统使用实体材质。设置页继续采用 Compose / Miuix 0.9.4。

## 设计约束

采样源排除导航自身。选中指示器不参与父布局测量，避免非整数屏幕密度下的尺寸反馈。子页在系统安全区就绪后布局正文，并在同一次测量中确定标题高度，保持短列表和长列表的重建阅读位置。

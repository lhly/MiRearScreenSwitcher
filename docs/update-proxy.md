# 更新镜像代理

在“关于 → 检查更新”下方打开“镜像代理”。默认关闭，选择保存在应用设置中，切页、重启和屏幕旋转均保留。开启后，版本清单和APK下载使用第三方GH-Proxy；关闭后恢复GitHub直连。检查进行中暂时禁用开关，切换后清除上次检查结果。网页源码仓库、提交反馈和Release浏览入口沿用GitHub原地址。

代理只用于公开更新文件，无需Token，不创建VPN，也不更改系统代理。每次检查读取当前设置，每次下载固定本次路由；已有下载及其后台/旋转生命周期仍由原弹窗管理。代理不可用时显示既有失败/重试提示，可取消弹窗后关闭代理再次检查。

## 第三方服务与安全

代理使用 `gh-proxy.com`，只加速公开的版本清单和 APK 文件请求。开启后会向该第三方服务发起请求，不能保证所有网络环境都可用。

代理不会放宽安装验证：下载完成后仍校验大小、SHA256、包名、升级版本及签名；APK 签名必须与已安装应用一致。代理开关不改变网页仓库、反馈和发布页的原地址。

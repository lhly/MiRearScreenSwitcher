# 设置 UI 统一与旧代码清理验收

2026-10-17，按用户要求删除 GlassUi，并将其全部调用方迁移到 Compose + Miuix 0.9.4。

## 清理与实现

- 删除 GlassUi.java、NativeAppPicker.java 及旧 Java 设置页/AlertDialog 渲染。
- 业务与生命周期控制保留为 SettingsController.java；所有设置目标由 MiuixSettingsUi.kt 渲染。
- MiuixComponents.kt 统一主题、卡片、设置行/开关、子页容器、数字/文本弹窗及更新弹窗。主窗口启动背景也与 Miuix 主题一致。
- 通知、关于、应用选择、权限检测、离线教程和应用内设置/更新弹窗已迁移。应用选择保留异步加载、按需图标、搜索/系统筛选、可见项批量操作和隐藏选中项。
- 更新任务与 ViewModel 会话继续处理下载、完整性/身份校验、安装权限与安装器返回；服务、磁贴、URI 和偏好键兼容。
- 移除无引用的旧酷安图像；导航模糊组件重命名为 BlurredNavigationFrame，以反映实际用途。
- 根 AGENTS.md 与设计 MASTER.md 明确唯一 Miuix 规范，历史 View/首页试点验收增加历史说明。

# 关于页入口与更新检查验证（初始实现）

后续检查更新已改为Raw版本清单，当前行为与验证见[Raw更新检查验证](raw-update-validation.md)。下文保留首次实现的历史验收记录。

2026-10-15完成关于页入口和更新检查的开发验收，包含Compose + Miuix首页改造；当前发布版本见README。

## 行为

- 当前关于页不再显示MRSS交流群或咖啡/打赏入口，保留原作者、上游测试贡献者和完整离线许可。
- GitHub仓库跳转维护分支`https://github.com/lhly/MiRearScreenSwitcher`；提交反馈直接打开`/issues/new`。
- 检查更新只由用户点击触发，使用公开GitHub latest release接口；区分发现新版、版本相同、本地构建较新、暂无正式版、请求受限、网络失败或无法识别版本。
- 按语义版本比较主/次/补丁与预览标识，忽略构建元数据；比较用SOURCE_TAG，避免debug后缀影响判断。示例：本地开发预览版本面对远端3.3.0时显示本地构建较新，不建议降级。
- 后台联网，连接/读取均10秒超时，最多读取256KiB；检查中禁用入口，防止重复任务。销毁时取消连接，离开关于页或切到后台时不弹出完成对话框。
- 新版本按钮打开本仓库相应发布页；不自动下载安装，不读取或携带GitHub凭据。响应中的任意html_url不会直接用作浏览器地址。
- 增加普通INTERNET权限，补齐简体、繁体和英文。失败可重试，也可打开发布记录。

接口依据：[GitHub官方latest release文档](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)。

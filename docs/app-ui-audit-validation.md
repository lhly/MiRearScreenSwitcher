## 实现约束

- `values/theme_colors.xml` 和 `values-night/theme_colors.xml` 统一管理 Compose、Activity 启动背景、通知窗口和录屏面板的主题色，避免再次分叉。
- 通知窗口背景与内容同步；重新解析卡片 Drawable，避免同资源 ID 导致主题切换后仍保留白卡片。
- 卡片跟随通知内容淡入，避免遮住入场的中心应用图标；原有通知阶段和退出/交接行为保留。
- 通知继续使用背屏 DPI 和刘海安全区，按实际可用高度限制正文 1–6 行并省略，保留系统字号。
- `ChargingLiquidView` 替代不再准确的 `LightningShapeView` 名称，删除模式开关及不可达绘制。逐段对比确认实际液体、波浪、气泡和逐帧调度方法保留。
- 明确保留充电绿色、录屏红色、冲突琥珀色及蓝色品牌图标；充电液体底部的黑色层次渐变也保留。
- 已更新 README、AGENTS 和设计规范；历史版本的变更记录保留为历史证据。

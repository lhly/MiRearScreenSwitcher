# 背屏动态玻璃充电动画验收

验收日期：2026-10-31。

## 实现范围

充电画面采用全屏绿色玻璃液体。Android 13+ 通过单次 GPU 绘制生成动态折射、内部光带、液面厚度和少量气泡；较早系统使用轻量 Canvas 兼容绘制。画面根据时间、电量和设备倾斜变化，不使用预先生成的图片或视频。

背景覆盖整个可绘制区域，电量和本地化充电状态独立绘制。文字按当前窗口的摄像头安全区居中，旋转后重新计算，不固定使用某一机型的左侧避让宽度。文字所在区域降低背景亮度，避免光带干扰阅读。

100% 使用独立的满电边界：液体填满顶部，倾斜或波浪不会产生黑色空隙；内部光流仍继续运动，状态改为“充电完成”。未满电时保留随电量变化的自由液面。

## 播放与生命周期

- 保留原有普通模式8秒退出、常亮模式拔线退出、通知打断、旧请求隔离和背屏任务恢复。
- 初次进入用2秒填充到目标电量；实时电量变化用600毫秒衔接当前液位。
- 普通动态绘制上限60fps；常亮播放8秒后，运动速度降为35%，绘制上限30fps。这些是调度上限，不代表真机实测帧率。
- 页面暂停、不可见、窗口移除、显示关闭或进入息屏状态时，停止连续绘制并注销传感器。暂停期间收到电量变化时，液位过渡同样暂停，恢复页面后接续。
- 系统关闭动画时直接显示目标电量，不持续运行材质动画。

## 正式版真机检查

设备为2509FPN0BC，Android 17 / HyperOS OS4.0.5.0.XPBCNXM，背屏976×596、450dpi。安装的是正式签名的 ReMRSS 3.6.0，包名 `top.zainzh.rearscreen`，没有 `DEBUGGABLE` 标志。通过正式充电页面的电量参数分别显示67%和100%，没有修改真实电池状态、系统动画设置或应用偏好，也没有安装调试版。

| 重点 | 结果 |
|---|---|
| 摄像头避让 | 通过。系统报告左侧296px为摄像头安全区；实际文字容器为 `[296,0][976,596]`，中心 `(636,298)`。两种状态下文字最左字形距安全边界分别为183px、133px，未重叠摄像头区域。 |
| 安全区居中 | 通过。67%/100%可见文字字形的整体中心约为 `(639,297)` / `(639.5,297)`，与安全区中心相符，未按整屏中心摆放。 |
| 满电填充 | 通过。100%真机截图没有顶部空气带；3秒录像的180帧逐帧检查中，可见安全区域顶部26行均保持绿色覆盖。 |
| 稳态动画 | 短时检查通过。未录屏复测的67%/100%更新频率约59.5/59.9fps，帧间隔P95约17.6/17.1ms；未见持续冻结。 |
| 入场动画 | 待优化。67%复测的入场阶段记录到约130.9ms帧完成耗时，随后一帧有约117ms的等待；长耗时主要位于图形渲染提交阶段，具体原因尚未定位。稳态恢复后没有同等级长帧。 |

不录屏稳态样本分别包含226/220帧，覆盖约3.78/3.66秒，排除前2.2秒入场阶段。`FrameCompleted - IntendedVsync` 的P95分别为6.13/5.98ms；最大绘制间隔约32.2/25.0ms，仍存在少量短长帧，因此不将结果描述为全程零掉帧。

更新频率按充电窗口自身的 `DrawStart` 时间去重计算，不混用主屏页面或整个进程帧数；此处fps表示应用绘制更新频率。测试覆盖普通8秒模式的短时画面与动画，未覆盖实体插拔电源触发、长时间常亮、温度和耗电。

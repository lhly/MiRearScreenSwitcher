# 更新弹窗与下载流程

2026-10-16完成以下本地验收，现已随[ReMRSS v3.3.3](https://github.com/lhly/MiRearScreenSwitcher/releases/tag/v3.3.3)发布；公开发布验证见[自动发版记录](github-release.md)。

## 交互

- 发现更新：标题只显示一次目标版本，正文显示当前版本和安装包大小；“下载更新”与“查看更新”保留。已是最新版时，只显示当前版本和结果，不再重复列出相同的“最新正式版”。
- 点击下载：继续使用同一个AlertDialog，直接显示进度条、百分比及已下载/总大小。下载/校验期间保留取消入口，失败后在原弹窗重试。
- 下载完成：沿用大小、SHA256、包名、版本和签名验证；通过后唤起系统安装器。缺少安装来源权限时，弹窗提供授权按钮；返回后重新校验文件再安装。取消系统安装后，可在弹窗再次安装。
- 关闭弹窗或退出Activity取消任务。切到后台继续下载，完成后等返回再安装；旋转/深浅色切换重建弹窗并保留任务，不重复下载或重复唤起安装器。
- 进程被系统回收后，仅恢复可下载提示，用户再次点击才重新下载；不恢复未经重新校验的文件或静默开启网络请求。

## 实现

`UpdateDialogController`承载结果与进度，`Session`由MainActivity的ViewModel保存，仅保留普通数据和applicationContext下载任务。旧弹窗销毁前移除异步回调，避免配置重建时误清理保留任务。安装URI交由`UpdateInstaller`构造，下载和APK验证协议保持不变。

移除`UpdateDownloadActivity`及Manifest声明，五套语言删除重复版本标签和旧页面说明。debug专用`FixtureUpdateActivity`继承真实MainActivity，只替换本地更新清单/下载传输和安装权限结果；生产包没有该入口或测试APK资源。

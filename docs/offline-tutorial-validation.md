# ReMRSS 离线使用教程验收

> 以下为最初实现的功能验收；本轮 Miuix 迁移后的界面与回归结果见 [统一 UI 验收](miuix-cleanup-validation.md)。

2026-10-17实现。仅保留本地修改和签名测试包，没有提交、推送或发布。

## 内容与入口

- 首页“控制中心快捷磁贴”分组明确显示“使用教程”，点击打开独立`TutorialActivity`。原`openTutorial`动作也进入该页面，不再发送外部网页Intent。
- 原生页面采用本地简繁英资源，覆盖Shizuku准备、按需授权、磁贴投放、截图录屏、显示常亮、背屏通知、后台与更新、故障排查与自动化8章。包含章节目录、返回目录、返回上页和阅读位置保存。
- 开始阅读或跳转章节不请求网络、不初始化WebView、不加载远端图片。页面中的原生图标、文字与步骤卡片均离线可用。
- “打开权限检测”进入现有独立权限页，返回后继续阅读；“打开Shizuku”沿用管理器入口，未安装时由用户主动打开其官网。
- 文末保留来源说明、原图文编写者和原作者署名。“查看原文”仅在点击时通过浏览器打开[腾讯教程](https://docs.qq.com/doc/DVWxpT3hQdHNPR3Zy?dver=)，明确说明原文为旧版图例且在线阅读需要联网。
- 自动化示例按当前运行包使用`mrss://`或`mrss-debug://`，没有将调试版示例错误指向正式包。

内容按当前源码与界面重写，未直接复制旧截图：切屏磁贴不负责再次点击返回；需等待连接完成，背屏已占用时应先移回主屏。录屏磁贴先打开悬浮控制台，录制通过悬浮按钮操作。截图位于`Pictures/RearDisplay`，视频位于`Movies`。授权、Android电池优化豁免和小米省电策略分别说明。

## 教程内添加磁贴（2026-10-18）

本节记录最初的系统确认方案；当前实现已按下节改为 Shizuku 直接添加。

- 正式代码中的“添加磁贴与投放”章节新增三个独立按钮，分别请求添加切屏、截图和录屏磁贴，沿用各自的名称和单色图标。Android 13 及以上通过系统确认窗口添加；旧版保留手动编辑控制中心的说明。
- 系统返回已添加、原本已存在、未添加、请求进行中或错误时，教程给出对应反馈；没有自动重试、批量弹窗或在添加后触发磁贴功能。简体、台港繁体与英文共五组资源同步。
- 独立调试包在小米 Android 17 真机验证：投放磁贴重复添加提示正确；截图与录屏出现各自的系统确认窗口，确认后实际进入磁贴列表；录屏取消提示及随后重试添加有效。测试新增的两个调试磁贴已移除，列表与测试前完全一致，原有正式版和调试版磁贴保留。
- 深色常规字号、浅色 1.3 倍字号、真实横屏滚动及旋转重建后阅读章节保留已截图检查，与首页复用 Miuix 主题。测试改变的字号、主题策略和主屏方向已恢复。
- Debug、AndroidTest 及 Release Java/Manifest 编译通过。现有教程四项 Espresso 测试在真机 API 37 因测试框架反射不到 `InputManager.getInstance()` 全部中断，未计为自动回归通过；按钮功能采用实际界面操作与系统磁贴列表独立核验。API 33 以下的隐藏分支经源码检查，未进行旧系统真机验证。
- 全量 Release Lint 被前序原型的六项错误阻断：`RearInputProxy` 两处 API 26 的带超时 `Process.waitFor`、`UriReceiverActivity` 一处 API 27 的 `setShowWhenLocked`，以及 `MiuixComponents` 三处 `LocalContextGetResourceValueCall`。新增教程按钮没有 Lint 错误；教程仅有原本外链代码的 `UseKtx` 建议。此次未改动这些前序原型文件，后续发版前需处理。

本轮日志与截图位于忽略目录 `.local/diagnostics/tutorial-tiles/`。未改版本号、未覆盖已安装正式版、未提交或发布。

## Shizuku 直接添加磁贴（2026-10-18）

- 按用户要求，正式教程的三个按钮改用现有 Shizuku 控制服务直接添加，移除教程对 `requestAddTileService` 的调用，不再出现尺寸选择或系统添加确认窗口。Shizuku 未启动、未授权或状态不可读时，提示先完成启动授权，保留控制中心手动添加说明。
- 三个组件固定来自应用自带的 TileService。后台执行 `cmd statusbar add-tile`，检查当前用户的 `sysui_qs_tiles` 确认实际添加；已有时不重复添加，不改写整个磁贴列表。执行期间三个按钮临时禁用，等待连接有超时，离开页面取消等待并释放该页面的服务连接。
- 小米 Android 17 真机：先验证 shell 直接添加，再通过新版教程点击录屏按钮，确认全程无弹窗、成功提示与列表新增对应组件一致；投放、截图和录屏三个按钮的已存在提示均通过，重复操作没有重复条目。只移除了本轮新增的调试录屏磁贴，保留测试前已有的三个正式版和两个调试版磁贴，列表恢复到本轮开始状态。
- Debug 与 Release Java/Manifest 编译通过，五组教程资源一致，浅色实际按钮与正文已截图核对。布局组件沿用上一轮已验证的深色、大字号、横屏方案；这轮未重跑这些视觉组合、前述 API 37 Espresso 不兼容测试或已知有六项原型错误的全量 Lint。缺少 Shizuku 的提示、连接超时及取消分支经过代码检查，未在当前已授权真机主动断开 Shizuku 进行故障注入。

# ReMRSS 使用指南

本指南按当前源码整理。已发布版本的功能以对应 [Release](https://github.com/lhly/MiRearScreenSwitcher/releases) 说明为准；当前源码可在“背屏”页打开离线“使用教程”，末尾保留腾讯原图文教程入口。

## 初次设置

1. 在支持背屏的小米设备上安装 ReMRSS。
2. 按 [Shizuku](https://shizuku.rikka.app/) 内的引导启动服务。
3. 打开 ReMRSS，完成 Shizuku 授权，等待控制服务连接。
4. 按需开启通知、充电动画等功能，再添加控制中心磁贴。

从旧 MRSS 迁移时，新包 `top.zainzh.rearscreen` 会独立安装，不会自动读取旧应用的配置和权限；需要重新配置、授权并添加磁贴。详见[迁移说明](remrss-identity-validation.md)。

## 控制中心磁贴

下拉控制中心，进入快捷开关编辑，添加以下三项：

| 磁贴 | 用途 |
| --- | --- |
| 切换至背屏 | 将主屏当前应用投放到背屏 |
| 获取背屏截图 | 截取背屏画面并保存到相册 |
| 背屏录屏 | 打开或关闭录屏悬浮控制台 |

### 投放与返回

1. 在主屏打开要投放的应用。
2. 下拉控制中心，点击“切换至背屏”。
3. 操作开始后控制中心自动收起，翻转手机查看背屏。

若磁贴显示“正在连接服务...”，请保持控制中心展开，连接等待最多 5 秒；提前收起可能取消请求。提示启动或授权 Shizuku 时，先按提示处理再重试。

要移回主屏，点击应用正在背屏运行的通知。启用接近传感器后，也可按“背屏”页的遮盖检测说明操作。

### 截图与录屏

- **截图**：背屏显示目标画面后，点击截图磁贴。图片保存在 `Pictures/RearDisplay`，可在相册或文件管理中查看。
- **录屏**：点击录屏磁贴打开悬浮按钮。点击红色圆形开始，再点击方形停止；视频保存在 `Movies/ReMRSS_*.mp4`。悬浮窗可拖动，停止录制后可点击关闭按钮退出。

## 显示、充电与通知

- **DPI 与方向**：在“背屏”页调整密度及 0° / 90° / 180° / 270° 方向，以操作后读回的实际状态为准；可还原默认 DPI。
- **常亮**：“背屏常亮”用于投放应用期间保持点亮，“持续唤醒”用于未投放应用时保持点亮，按需选择。
- **充电动画**：开启后接通电源显示绿色液体动画；需要充电期间持续显示时，再开启“充电动画常亮”。
- **背屏通知**：在“通知”页开启服务并选择来源应用，可设置隐藏标题/内容、跟随勿扰、仅倒扣时通知和自动销毁时间。允许本应用发送通知不能代替通知使用权。

## 权限与后台运行

当前源码在“关于 → 权限检测”中集中显示用途、状态和授权入口，从系统设置返回后自动刷新。按自己使用的功能授权即可。

| 权限或设置 | 使用场景 |
| --- | --- |
| Shizuku | 背屏切换、截图、录屏、显示控制及通知/充电动画 |
| 通知使用权 | 读取所选来源应用的通知并显示到背屏 |
| 通知发送 | 显示本应用的通知，Android 13 及以上需运行时授权 |
| 显示在其他应用上层 | 显示录屏悬浮控制按钮 |
| 应用列表访问 | 搜索和选择通知来源应用 |
| 安装未知应用 | 安装应用内下载的更新时使用 |

只手动使用磁贴时，通常无需锁定后台。长期使用通知、充电动画或常亮时，可检查后台运行、自启动与省电限制。ReMRSS 不显示在最近任务中，无需专门加锁。

“后台运行建议”检测的是 Android 电池优化豁免，小米应用省电的“无限制”是另一项设置。自启动和厂商省电策略无法可靠自动检测，应用会提示手动检查，并提供系统设置入口。

开启自启动不代表开机恢复全部功能。手机重启后，先启动 Shizuku，再打开 ReMRSS 恢复已启用的功能。

## 自动化调用

在“关于 → 自动化入口”中查看或复制 URI，可用于 Tasker、MacroDroid 等自动化工具。

| 操作 | URI 示例 |
| --- | --- |
| 投放当前应用 | `mrss://switch?current=1` |
| 投放指定应用 | `mrss://switch?packageName=com.example.app` |
| 返回主屏 | `mrss://return?current=1` |
| 截图 | `mrss://screenshot` |
| 调整显示 | `mrss://config?dpi=300&rotation=1` |

`rotation` 使用 `0` / `1` / `2` / `3`，分别对应 0° / 90° / 180° / 270°，并非直接传角度。

正式包为 `top.zainzh.rearscreen`；调试包为 `top.zainzh.rearscreen.debug`，调试协议为 `mrss-debug://`。若同时安装了其他处理 `mrss://` 的应用，请在自动化工具中指定 ReMRSS 目标包，避免命中旧版。

## 更新与排查

在“关于 → 检查更新”中手动检查。下载后应用会校验大小、SHA256、包名、版本和签名，再交给系统安装器确认；需要时再授予安装来源权限。

- **服务未连接**：确认 Shizuku 正在运行且 ReMRSS 已授权，再重新展开控制中心重试。
- **背屏已占用或投放内容消失**：先将原应用移回主屏，再重新投放。
- **通知未出现**：检查来源应用是否产生新通知、应用选择、通知使用权、勿扰/倒扣条件和后台限制。
- **充电动画未出现**：检查功能开关、Shizuku 状态及后台限制。

仍有问题时，在“关于 → 诊断信息”查看连接状态，向 [Issues](https://github.com/lhly/MiRearScreenSwitcher/issues) 提供机型、系统版本、操作步骤和实际现象。

# 从旧 MRSS 迁移

ReMRSS 正式包名为 `top.zainzh.rearscreen`，与旧 MRSS 属于不同应用，可以同时安装。首次迁移不会自动读取旧应用的配置、权限或磁贴，也不会自动卸载旧应用。

## 重新设置

1. 安装 ReMRSS，按[使用指南](usage.md)完成权限来源的授权与连接。
2. 重新选择通知来源、显示与充电等设置，并按需授予通知使用权、悬浮窗等权限。
3. 为 ReMRSS 重新添加控制中心磁贴；确认可用后再移除旧应用的磁贴。
4. 检查自动化工具中的目标包名，避免调用旧应用。

## 避免自动化协议冲突

正式版继续使用 `mrss://`。若旧应用也注册了该协议，系统可能把调用交给旧应用；请在 Tasker、MacroDroid 等工具中明确指定 ReMRSS 包名 `top.zainzh.rearscreen`。

应用检测到其他可见的协议处理应用时会显示警告及相关应用名称、包名。提示不会执行自动化命令，也不会修改默认应用、停用或卸载其他应用；其他用户或工作资料中的不可见应用可能无法检测。

调试版包名为 `top.zainzh.rearscreen.debug`，协议为 `mrss-debug://`，其设置和权限与正式版分开。

## 后续更新

迁移后，同包名、同签名的 ReMRSS 更新可以覆盖安装并保留数据。请通过 ReMRSS 的更新入口或本仓库正式发布页更新，不要使用旧 MRSS 的更新入口代替。

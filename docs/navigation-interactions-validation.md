# 页签交互与维护者展示验证

2026-10-16完成页签交互改造；下文为发布前本地验收，改动随v3.3.2发布。

## 行为

- 正式应用名称简化为MRSS。关于页顶部只显示应用名和版本，当前维护者放在“源码仓库”的说明中；README和后续Release模板移除重复个人标识。NOTICE和源码中的版权/贡献署名保留。
- 背屏、通知、关于由Compose HorizontalPager承载。左右拖动跟随手指，松手由Pager完成速度处理和停靠，首尾页不循环。
- 点击底栏使用250ms水平移动，曲线为`CubicBezierEasing(.77f, 0f, .175f, 1f)`；快速点击可从当前进度反向。导航选中背景与图标颜色在绘制阶段跟随Pager位置，避免每帧重组整组导航；文字随实际选中状态变化。
- 系统动画时长为0时，点击直接定位。应用选择保留为独立子页，隐藏底栏并禁用主页面滑动；进入时底层定位到通知页，实际系统返回已验证回到通知页。
- 通知和关于使用独立原生容器，页面切换保留滚动位置；首页LazyList状态、各页位置和对话框输入继续支持Activity重建。
- 页面停靠后同步Java活动页面。动画被触摸打断并回到原页也会同步，更新检查结果不会因过期页码在错误页面弹出。

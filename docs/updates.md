# 下载与更新

在应用的“检查更新”入口检查新版本，也可以从 [GitHub 最新正式版](https://github.com/lhly/ReMRSS/releases/latest) 下载 APK。

## 应用内更新

1. 打开“检查更新”。发现新版本后查看版本说明，点击“下载更新”。
2. 等待下载和校验完成。下载期间可以取消，失败后可重试。
3. 如果系统要求安装来源权限，按提示允许 ReMRSS 安装应用，返回后继续。
4. 在系统安装器中确认安装。同包名、同签名的正常更新会保留应用数据。

应用会检查安装包大小、SHA256、包名、版本和签名。校验失败时不会交给系统安装器，不要通过卸载现有版本来绕过签名不一致的提示。

## 下载失败时

- 确认网络可用，稍后重试；也可从发布页手动下载。
- GitHub 直连受限时，可尝试[更新镜像代理](update-proxy.md)。
- 已启用代理但仍失败时，关闭代理后重新检查或下载。
- 从旧 MRSS 首次迁移到 ReMRSS 属于独立安装，参见[迁移说明](migration.md)。

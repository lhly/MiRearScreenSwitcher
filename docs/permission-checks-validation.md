# 关于页权限检测验收

> 以下为最初实现的功能验收；本轮 Miuix 迁移后的界面与回归结果见 [统一 UI 验收](miuix-cleanup-validation.md)。

2026-10-17完成开发和模拟器验收；未提交、推送或发布新版本。

## 行为

关于页只保留一个“权限检测”菜单入口，点击后打开带返回按钮的独立页面，集中展示“权限检测”和“后台运行建议”。每项展示功能用途、当前状态和按需授权/设置入口；已授权项隐藏授权按钮。状态在从系统设置返回时立即刷新，停留检测页面时也会定期更新。返回按钮或系统返回均回到原关于页，保留滚动位置；权限页面自身也保存旋转/重建前的滚动位置。支持简体、繁体（台湾/香港）和英文。

| 项目 | 对应功能 | 检测与入口 |
| --- | --- | --- |
| Shizuku | 背屏切换、截图、录屏、显示设置、通知与充电动画 | 区分未运行/未连接、未授权及已授权；运行中请求授权，永久拒绝时打开管理器。未安装时打开官方网站。 |
| 通知使用权 | 读取所选应用通知并显示到背屏 | 检测本应用指定Listener组件；优先打开该组件授权详情，兼容旧系统的通知使用权列表。 |
| 发送通知 | 服务状态、录屏控制、更新下载进度 | 检测应用通知总开关及Android13+运行时权限；进入本应用通知设置。未授权不等于前台服务不能运行。 |
| 显示在其他应用上层 | 录屏悬浮控制按钮 | 使用系统悬浮窗检测接口，打开悬浮窗授权设置。 |
| 安装未知应用 | 下载更新后交由系统安装APK | Android8+检测本应用安装来源开关并跳转；旧系统显示无需单独授权。 |
| 电池优化豁免 | 长期运行通知、充电动画及常亮 | 检测标准Android电池优化白名单，打开电池优化管理页，不新增直接请求豁免权限。 |
| 后台省电策略 | 长期后台运行 | 标记需手动检查；优先小米应用省电页，不可用时回退到本应用信息。 |
| 自启动 | 后台运行建议 | 标记需手动检查；优先小米自启动管理页，不可用时回退到本应用信息。 |

检测失败时显示“暂时无法检测”，不把读取失败解释成已授权。设置Activity不存在或不可访问时逐级回退到公共设置、应用信息及系统设置；全部失败时显示可操作提示。Intent中的包名使用当前运行包名，支持正式包和调试包。

厂商后台策略与自启动没有通用可靠的状态接口，不能标为自动检测完成。Android电池优化白名单不等于小米省电“无限制”。页面说明锁后台为可选措施，当前应用隐藏于最近任务；开机后仍需启动Shizuku并打开应用恢复已启用的功能。没有新增开机恢复行为。

仅列出当前功能实际使用、需要用户配置的权限：不因Manifest中的遗留声明诱导开启麦克风或存储权限，也不把系统自动授予的普通权限列为待授权。

## 验证

- API36模拟器12项权限运行回归通过：真实Overlay授权/撤销、返回刷新及滚动/视图保持、指定Listener授权/撤销、电池优化白名单变化、状态读取失败、手动状态、设置参数、按钮路由、私有/不存在设置Activity回退和完全不可用情况；新增关于页只保留菜单、打开独立页面再返回保持原位置，以及独立页面重建后恢复滚动位置。
- 布局修正后重新运行上述12项和原关于页/设置13项，共25项通过。链接、更新、代理开关及页面/输入状态保存正常；检测后端没有改变，沿用此前发布与Shizuku连接32项主机回归通过的结果。
- Debug、AndroidTest和R8签名Release构建成功；Lint为0错误、57项既有警告。
- 正式APK通过现有校验器：包名`top.zainzh.rearscreen`、当前版本`3.3.4/2016`、不可调试、原正式证书及完整许可资产均正确。仅生成本地测试产物，没有改变版本号或公开更新清单。
- 初版简繁英文案已检查；独立界面追加6张截图，覆盖紧凑关于页菜单、独立页浅色/深色/英文1.4倍字号/横屏以及真实点击返回关于页。长说明和按钮允许换行，触达区域至少48dp，状态含文字及可访问名称。独立页面最大宽度680dp，不显示底部主导航。截图与日志保存在忽略目录`.local/diagnostics/permissions-20261017/`。
- 真实点击悬浮窗按钮已进入`com.android.settings`。ROM可能先显示授权应用列表；系统允许范围内优先进入目标应用，不能承诺所有ROM均直接显示单个开关。

本轮无连接中的小米真机；小米私有设置页是否存在取决于HyperOS版本，回退与状态边界已覆盖，尚未在该机型实测。模拟器测试只修改独立调试包权限，并恢复Listener、Overlay、电池白名单、应用语言、主题和字号。

接口依据：[Android Settings](https://developer.android.com/reference/android/provider/Settings)、[NotificationManager](https://developer.android.com/reference/android/app/NotificationManager)、[PackageManager](https://developer.android.com/reference/android/content/pm/PackageManager)、[Shizuku API授权说明](https://github.com/RikkaApps/Shizuku-API#request-permission)。

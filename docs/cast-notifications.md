# 投放中的紧凑通知

虚拟投放期间，符合通知总开关、应用选择、勿扰和倒扣条件的通知，会显示为摄像头安全区顶部的紧凑胶囊。图标、标题和一行摘要覆盖在原投放画面上，不缩小或移动画面，不启动通知 Activity，也不暂停投放或切换背屏任务。

全屏通知或充电页面显示期间主动开始投放，会结束旧提示并撤销其归还操作；旧提示到期不会停止新投放。后续新通知和充电提示继续按当前投放模式显示。

胶囊按已有的“通知显示时长”自动消失，无障碍建议时长可能延长显示。连续通知直接替换当前内容并重新计时，不排队展示已经过期的消息。长文字在行尾截断；标题、正文的隐私设置和通知暗夜模式继续生效，常规模式跟随系统深浅色。

点按胶囊会立即关闭，不跳转或展开。胶囊范围内从按下到抬起的完整手势由通知消费，不会点击到下方 App；区域外继续沿用投放触摸路径。拖动或多指不会误关闭通知，通知到期或替换也不会把仍按住的手指转成 App 点击。打开投放菜单、切换显示范围、暂停或关闭屏幕时，胶囊隐藏；恢复可见时，只显示仍未过期的最新通知。结束投放后清除内容和定时任务。

没有虚拟投放宿主时，继续使用原全屏通知流程。物理直投保持原显示流程。虚拟投放期间插电改用同一胶囊，显示充电状态和当前电量，8秒自动消失或点按关闭；充电常亮开关不会让胶囊长期覆盖投放。重复同一次插电不会重新弹出，拔线仅清理仍显示的充电提示。消息与充电胶囊按最新事件替换，拔线不关闭后来的消息。没有投放宿主时，充电仍使用原来的全屏/常亮动画。
